
# PixoraSnap

AI-powered event photo sharing and discovery platform.

## About

PixoraSnap is a mobile-friendly event photo-sharing
platform that helps users discover their event photos
using AI-powered face matching.

## Core Features

- User authentication
- Event creation and management
- Event photo uploads
- Invitation links and QR codes
- AI-powered face matching
- Personal photo gallery
- Photo downloads and favorites
- Progressive Web App (PWA)

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### AI Service
- Python
- FastAPI

### Storage
- Cloudflare R2
